# =============================================================================
# VidSense — Python dependencies (Python 3.11, Windows)

# INSTALL ORDER MATTERS. Install the CPU build of PyTorch FIRST, from the CPU
# wheel index, so pip does not pull the multi-GB CUDA build. Everything here
# runs on CPU by default (device: auto falls back to CPU when no CUDA runtime
# is present), which keeps the 4 GB of VRAM on the T1000 free.
#
#   python -m pip install torch==2.9.1 torchaudio==2.9.1 --index-url https://download.pytorch.org/whl/cpu
#   python -m pip install -r requirements.txt
#
# The heavy speech models (ASR / wav2vec2 alignment / pyannote diarization) are
# NEVER co-resident: the pipeline loads one, uses it, releases it, then loads
# the next (see modules/workflow/pipeline.py).
# =============================================================================
